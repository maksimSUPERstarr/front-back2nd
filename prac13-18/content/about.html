О приложении

Это учебное PWA-приложение для контрольной работы по фронтенд и бэкенд разработке. Оно объединяет практические задания по офлайн-режиму, App Shell, WebSocket и push-уведомлениям.

Основные возможности

  • создание и хранение заметок в localStorage;
  • работа в офлайн-режиме через Service Worker;
  • установка приложения как PWA;
  • динамическая загрузка страниц внутри App Shell;
  • оповещения о новых задачах через WebSocket;
  • push-уведомления и напоминания;
  • отложить напоминание на 5 минут.

Используемые технологии

  • HTML5, CSS3, JavaScript
  • Node.js + Express
  • Socket.IO
  • Service Worker
  • Web App Manifest
  • Push API + web-push

Назначение

Приложение демонстрирует современный подход к созданию веб-приложений, которые работают как устанавливаемые и частично автономные программы.
