# Менеджер заметок PWA

Учебный проект по практическим занятиям №13-18 по дисциплине «Фронтенд и бэкенд разработка».

## Что реализовано

- управление заметками и задачами;
- сохранение данных в `localStorage`;
- Service Worker с офлайн-режимом;
- App Shell с динамическими страницами `home` и `about`;
- Web App Manifest и набор PNG-иконок;
- локальный HTTPS-сервер на Express;
- обмен событиями через Socket.IO;
- подписка и отписка от push-уведомлений;
- напоминания с планированием через `setTimeout`;
- действие уведомления «Отложить на 5 минут».

## Запуск

```bash
npm install
npm start
```

После запуска откройте:

```text
https://localhost:3000
```

Браузер может показать предупреждение о самоподписанном сертификате. Для учебного локального проекта это ожидаемо.

Если проект запускается на новом компьютере после клонирования с GitHub, нужно создать локальный HTTPS-сертификат в папке `cert` или указать свои пути в `.env`. Локальные сертификаты и `.env` не добавляются в репозиторий.

## Проверка по заданиям

1. Добавьте обычную заметку и убедитесь, что она сохраняется после перезагрузки.
2. Отключите сеть в DevTools и обновите страницу: интерфейс должен загрузиться из кэша.
3. Откройте вторую вкладку приложения и добавьте заметку в первой: во второй должно появиться уведомление через WebSocket.
4. Нажмите «Включить уведомления» и разрешите уведомления в браузере.
5. Создайте заметку с будущим временем напоминания и дождитесь push-уведомления.
6. В уведомлении проверьте действие «Отложить на 5 минут».
7. На вкладке Application в DevTools проверьте Manifest, Service Worker и Cache Storage.

## Основные файлы

- `index.html` - App Shell и подключение PWA-ресурсов;
- `app.js` - клиентская логика заметок, Socket.IO, Push API;
- `sw.js` - Service Worker, кэширование, push и notification actions;
- `server.js` - HTTPS Express-сервер, Socket.IO, push и напоминания;
- `manifest.json` - настройки устанавливаемого PWA;
- `content/home.html` и `content/about.html` - динамические страницы приложения.

## Примечания

Файл `.env` содержит локальные VAPID-ключи и не должен попадать в репозиторий. Для публикации проекта достаточно оставить `.env.example`, а ключи сгенерировать заново командой:

```bash
npm run vapid
```
