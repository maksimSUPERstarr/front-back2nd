# Отчет по практике 25

Команда проверки:

```bash
npm run build
```

Результат сборки:

- `AboutPage-*.js` - отдельный lazy chunk для маршрута `/about`.
- `react-*.js` - отдельный vendor chunk для React.
- `bundle-report.html` - отчет `rollup-plugin-visualizer`.

Скриншот отчета анализатора должен находиться рядом с этим файлом: `bundle-report.png`.
